# Editing the Holden Health website

Open **Content → Edit your website** in Kelsey's admin portal.

## Menu and buttons

Expand **Website header — menu and buttons**. Change the menu labels and destinations, including Join now, Free call, The App, and Log in. You can hide Join now, Free call, or The App using their checkboxes.

Click **Publish website header**. These settings apply across the public website and its mobile menu. Allow a few minutes for cached settings to refresh.

## App section and page content

Choose **Home**, then expand **Edit page text and search appearance**. Under **The Holden Health app**, edit the headline, description, benefits, access note, buttons, and preview copy. The page preview reflects your changes before publication.

The visual editor also lets you click page text, images, and sections to edit them. Clicking the header opens the shared header settings.

Click **Publish Home** when ready. Other pages have their own Publish button. Unpublished page edits do not change the live website. Routine content changes do not need a developer deployment.

## Search appearance

Each existing page includes Page title and Search description fields. These update the rendered page's metadata. The site's initial HTML and previews from services that do not run JavaScript still use the deployed baseline metadata. Significant SEO changes should also be synchronized into the static HTML before launch.

Publishing content does not announce the website or remove its preview password. Launch access is controlled separately.
