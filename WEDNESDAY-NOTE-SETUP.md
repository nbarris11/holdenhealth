# The Wednesday Note: launch setup

The website is ready to collect subscribers. Before promoting the list, finish these outside-the-code steps.

## 1. Confirm Netlify is receiving signups

1. Deploy the site to Netlify.
2. Submit a test email through `wednesday-note.html`.
3. In Netlify, open **Forms → wednesday-note** and confirm the email appears.
4. Under form notifications, send new-submission alerts to `HoldenHealth.Coaching@gmail.com`.

## 2. Connect an email platform

Recommended: use MailerLite for the subscriber list and weekly sends. Create a group named **The Wednesday Note**, turn on double opt-in, and include an unsubscribe link in every email.

Until that connection is made, Netlify will safely collect addresses, but it will not automatically send the weekly email. Kelsey can export the Netlify list as CSV and import it into MailerLite.

## 3. Send the first issue

Use the copy on `wednesday-note.html` as the first email. Keep future Notes to the same simple format:

- one real-life problem;
- one perspective shift;
- one action someone can do today;
- one soft link to the Wednesday Reset or a free call.

## 4. Check before each send

- Write in Kelsey's actual voice and add a detail from her week when it fits.
- Test every link on a phone.
- Never add a subscriber who did not opt in.
- Do not use health promises, guaranteed results, or manufactured urgency.
